REI DAS MOTOS - APP FINANCEIRO MVP

Versão inicial: controle de entradas/saídas, categorias, filtros por mês, busca, exclusão de lançamento e exportação CSV.

Como abrir:
- Extraia o ZIP e abra index.html em um navegador.
- Para melhor experiência e instalação como app, hospede a pasta em um site HTTPS (ex.: GitHub Pages) e use a opção "Adicionar à tela inicial" do navegador.

IMPORTANTE:
- Dados ficam armazenados no navegador/dispositivo (localStorage); não há sincronização entre dispositivos nesta versão.
- Faça backup com Exportar CSV regularmente.
- CSV pode abrir no Excel ou Google Planilhas.
